# DeviceOps
A device management tool based on Device Owner API

---

## 权限授予

由于本应用依赖 **Device Owner API**，安装后需通过 ADB 手动授予最高管理权限：

1. **退出设备上所有账号**（如 Google、三星、小米、华为账号等，否则权限授予将失败）。
2. 连接电脑，在命令行输入：
   `adb shell dpm set-device-owner "com.android.deviceops/.DeviceAdminReceiver"`
3. 看到输出 **Success** 字符后，即激活成功。
4. 此时可以重新登录你的账号。

> **注意：** 权限仅需一次授权，设备重启依然有效。如需解除权限，只能通过应用内的“卸载”功能来关闭授权并移除。

本工具提供两个版本，功能逻辑完全一致，仅在入口处有所区别：

| 版本类型 | 应用名称 | 应用图标 | 进入方式 |
| :--- | :--- | :--- | :--- |
| **Native (普通版)** | DeviceOps | 原生图标 | 直接启动 |
| **Entry (伪装版)** | SmartThings | 三星官方图标 | 启动后显示“请连接手机”伪装界面。短按“确定”退出；**长按“确定”满 0.79 秒**即可进入真实界面。 |

## 核心功能

### 1. HTTP Proxy
针对 **OneUI 8.0+** 内核移除 TUN 模块的现状，DeviceOps 提供了 HTTP Proxy 功能作为网络调试的替代方案。即使在无 TUN 支持的环境下，也能实现高效的流量代理与分发。

### 2. 管理/停用应用
基于 Device Owner 级别的 `setApplicationHidden` 接口实现。
* **无需二次 ADB 授权：** 激活后可直接在 App 内开关应用状态。
* **隔离机制：** 该停用方式基于多用户隔离逻辑，不同于常规的“冻结”。被停用的应用会从系统桌面及“系统设置-应用列表”中彻底消失，**只能**通过本应用重新启用。
